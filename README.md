# G3 Architect - Modern Architecture Web App

A sleek, modern, and fully responsive single-page website for an architecture firm built with pure **HTML5** and **CSS3**. Designed with elegance, minimalism, and professional aesthetics to showcase architectural excellence.

## 📋 Features

- **Fully Responsive Design** – Optimized for Mobile, Tablet, and Laptop/Desktop
- **Modern & Elegant UI** – Clean minimalist architecture-inspired design
- **Smooth Navigation** – Sticky Navbar with smooth scrolling
- **Hero Banner** – Eye-catching full-width banner with call-to-action
- **Features Grid** – Beautiful card-based grid layout with "Explore More" buttons
- **Feature Details Section** – In-depth showcase of core services
- **Statistics Section** – Animated counters for:
  - Awards Won
  - Projects Finished
  - Clients Worked With
  - Emails Sent (Project Inquiries)
- **Sponsors / Partners Section** – Logo carousel/grid of trusted business partners
- **Professional Footer** – Comprehensive links, contact info, and social icons
- **No JavaScript Framework** – Pure vanilla HTML + CSS (lightweight & fast)

---

## 🛠️ Technologies Used

- **HTML5** – Semantic markup
- **CSS3** – Flexbox, Grid, Custom Properties, Animations, Transitions
- **Google Fonts** – Inter + Playfair Display (or any elegant font pair)
- **Font Awesome** – For icons (optional, CDN included)
- **Responsive Units** – `rem`, `vw`, `vh`, media queries
